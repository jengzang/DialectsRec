# 暨大句库地方特色分流

按用户已确认的四库方案执行，不再重复询问审批：暨大·潮州（默认）、暨大·苏州、AI 通用补充、暨大·地方特色；第四库以类别“潮州”“苏州”呈现两个 part。

通过本地 OpenAI 兼容 Responses API、gpt-6-luna、stream=true、store=false、最多五并发，逐条审查 2,230+5,498 条原文。每批提供相邻上下文，只输出目标条目的判定。地方词、食物、民俗、俗语、谐音及依赖地方背景的表达分入地方特色；仅提及地名的普通表达不因此迁移。疑难项二次复核。录音指令、释义、文本异常另标 quality flags，不能冒充地方特色。不得由关键词规则替代模型判定。

原始文本与编号不改写；内部 ID 使用 CZ_/SZ_ 来源命名空间，notes 存来源、原编号、原行号、判定理由和质量标记。保留重复句。原稿中的 & 标记保留并在界面说明不用朗读。审计文件保留每条原文、模型判定、源文件 SHA256、prompt 与批次结果；构建以审查完整且编号集合精确相等为前提。

App 内置四库，首次安装默认暨大·潮州；升级保留已有录音、选定句库及队列。首页提供句库选择，第四库按类别选择 part，录音随机、完整进度固定原顺序。各句库/版本/发音人独立保存任务。导出继续携带原文和来源 metadata。旧 AI 句库标识与版本保持，以保护已有数据。

验证：审查结果全量覆盖与总数守恒、命名空间/原文一致、checkpoint 复用安全、数据 hash；安卓单元测试和隔离数据库 instrumentation 覆盖默认选择、切库恢复、升级与导出，模拟器实际录音/试听/导出回归；版本升级 1.6 / code 7，打包并复核后合 main 推送。
